# Instalación

DaloyJS es compatible con **Node.js 24 LTS o con Node.js 26 y versiones posteriores** (`engines.node`: `^24.0.0 || >=26.0.0`) y se distribuye en el registro público de npm como `@daloyjs/core`. El paquete **no tiene peer dependencies**, así que `npm`, `yarn`, `pnpm` y `bun` pueden instalarlo directamente. *Recomendamos* [pnpm](https://pnpm.io/motivation) junto con los valores por defecto reforzados de `.npmrc` que verás más abajo, por motivos de seguridad en la cadena de suministro, aunque no es obligatorio. La entrada `engines.pnpm` de `package.json` es solo informativa, mientras que `engines.node` indica qué entornos de ejecución son compatibles y, según tu gestor de paquetes y la configuración de `engine-strict`, puede mostrar una advertencia o hacer que la instalación falle.

## La forma más rápida: crea un proyecto

Usa el generador oficial: con un solo comando configura un `.npmrc` reforzado, TypeScript en modo estricto y una ruta que ya funciona.

Enlaces a los paquetes: [create-daloy en npm](https://www.npmjs.com/package/create-daloy) y [@daloyjs/core en npm](https://www.npmjs.com/package/@daloyjs/core).

```bash
# elige un gestor de paquetes
pnpm create daloy@latest my-api
npm  create daloy@latest my-api
yarn create daloy           my-api
bun  create daloy           my-api
```

Consulta [Scaffold a project](/docs/scaffolder) (en inglés) para ver las plantillas y las opciones disponibles.

## O instálalo en un proyecto existente

### Requisitos previos

- **Node.js** 24 LTS, o 26.0.0 y versiones posteriores (Node.js 25 no es compatible).
- Un gestor de paquetes. Cualquiera de estos sirve. Para reforzar la cadena de suministro se recomienda pnpm 11.x o una versión posterior, pero `npm`, `yarn` y `bun` instalan `@daloyjs/core` sin problemas porque el paquete no tiene peer dependencies.

Para activar pnpm mediante [Corepack](https://nodejs.org/api/corepack.html):

```bash
corepack enable
corepack prepare pnpm@11.1.3 --activate
pnpm --version
```

<PackageInstall packages="@daloyjs/core zod" />

El paquete del framework publicado en npm es [@daloyjs/core](https://www.npmjs.com/package/@daloyjs/core).

## Configuración de instalación reforzada [#hardened-npmrc]

En pnpm 11 o versiones posteriores, coloca la configuración de la cadena de suministro en `pnpm-workspace.yaml`, en la raíz de tu proyecto (con las claves en camelCase; pnpm 11 lee este archivo incluso en proyectos de un solo paquete). pnpm 11 ignora esta configuración si está en `.npmrc`, así que si solo usas `.npmrc` no tendrás el periodo de espera ni la política de scripts.

```yaml title="pnpm-workspace.yaml"
minimumReleaseAge: 1440
blockExoticSubdeps: true
ignoreScripts: true
strictPeerDependencies: true
verifyStoreIntegrity: true
preferFrozenLockfile: true
autoInstallPeers: true
```

Para npm y versiones anteriores de pnpm, mantén también los mismos valores en `.npmrc`:

```ini title=".npmrc"
auto-install-peers=true
strict-peer-dependencies=true
prefer-frozen-lockfile=true
verify-store-integrity=true
minimum-release-age=1440
ignore-scripts=true
```

El periodo de espera e `ignoreScripts` reducen el riesgo en la cadena de suministro para estas instalaciones, pero no detienen todos los ataques. `ignoreScripts` bloquea el código malicioso en los scripts de instalación, no el código que se ejecuta al importar un paquete, y el periodo de espera de 24 horas solo protege frente a paquetes comprometidos que se detectan en menos de un día.

Consulta los motivos en [Seguridad](/docs/security) y en la [explicación de por qué usar pnpm](https://pnpm.io/motivation) (en inglés).

<a id="comprueba-la-instalación"></a>

## Verifica la instalación

Después de instalar, ejecuta esto desde la raíz del proyecto. Funciona igual con pnpm, npm, yarn o bun, porque llama directamente a `node`:

```bash
node -e "import('@daloyjs/core').then(m => console.log('DaloyJS ok ->', Object.keys(m).slice(0, 6)))"
```
