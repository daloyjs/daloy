## 1. Crea el proyecto

```bash
mkdir hello-daloy && cd hello-daloy
pnpm init
pnpm add @daloyjs/core zod
pnpm add -D typescript @types/node
```

```json
// package.json, añade esto
{
  "type": "module",
  "scripts": {
    "dev": "node --watch src/index.ts",
    "start": "node src/index.ts"
  }
}
```

Node.js ejecuta directamente los puntos de entrada escritos en TypeScript gracias a la eliminación de tipos integrada (type stripping), estable desde Node 24 y disponible desde la versión 22.18. Por eso, en desarrollo local no necesitas un transpilador ni un paso de compilación aparte.

Aquí usamos `src/index.ts` y `--watch` para que la estructura coincida con la que genera create-daloy. Así puedes copiar y pegar código entre esta guía y un proyecto generado sin cambiar el nombre de ningún archivo.

## 2. Escribe tu primera ruta

```ts
// src/index.ts
import { z } from "zod";
import { App, requestId, rateLimit } from "@daloyjs/core";
import { serve } from "@daloyjs/core/node";

const app = new App({
  bodyLimitBytes: 64 * 1024,
  requestTimeoutMs: 5_000,
})
  .use(requestId())
  .use(rateLimit({ windowMs: 60_000, max: 120 }))
  .get(
    "/greet/:name",
    {
      tags: ["Demo"],
      request: { params: z.object({ name: z.string().min(1) }) },
      responses: {
        200: { description: "Greeting", body: z.object({ msg: z.string() }) },
      },
    },
    async ({ params }) => ({
      status: 200,
      body: { msg: `Hello, ${params.name}!` },
    }),
  );

const { port } = serve(app, { port: 3000 });
console.log(`listening on http://localhost:${port}`);
```

`new App()` ya aplica `secureHeaders()` automáticamente. Regístralo solo si quieres reemplazar los valores por defecto.

¿Prefieres el panel de inicio con colores que incluyen las plantillas de `create-daloy`? Sustituye el `console.log` simple por `printStartupBanner()` de `@daloyjs/core/banner`. Muestra un banner enmarcado con el nombre de tu aplicación, la URL y cualquier enlace adicional (documentación de la API, comprobación de estado, etc.). El color se activa si la salida es una terminal (TTY), con `NO_COLOR` y `FORCE_COLOR` como ajustes manuales. Los caracteres ASCII, en cambio, los elige `detectAscii()` según el entorno y la plataforma (por ejemplo, `DALOY_ASCII`, el sistema operativo y la configuración regional), no según si la salida es una TTY:

```ts
import { printStartupBanner } from "@daloyjs/core/banner";

const { port } = serve(app, { port: 3000 });
printStartupBanner({
  name: "MyAPI",
  version: "1.0.0",
  url: `http://localhost:${port}`,
  runtime: "Node.js",
  links: [
    { label: "API docs", url: `http://localhost:${port}/docs` },
    { label: "OpenAPI JSON", url: `http://localhost:${port}/openapi.json` },
    { label: "OpenAPI YAML", url: `http://localhost:${port}/openapi.yaml` },
    { label: "Health", url: `http://localhost:${port}/healthz` },
  ],
});
```

```bash
pnpm dev
# en otra terminal
curl http://localhost:3000/greet/world
# -> {"msg":"Hello, world!"}
```

¿No quieres iniciar un servidor real? Cada `App` expone `app.request(input, init?)`, un cliente de pruebas que se ejecuta en el mismo proceso: recibe una URL o un objeto `Request` y devuelve un objeto `Response`, sin pila de red, sin puerto y sin abrir otra terminal. Es el mismo punto de entrada que usan el cliente tipado y la guía de pruebas:

```ts
const res = await app.request("/greet/world");
console.log(res.status, await res.json());
// -> 200 { msg: "Hello, world!" }
```

## 3. Añade OpenAPI y la interfaz de documentación [#3-add-openapi-and-docs-ui]

Con una sola línea en el constructor de `App`, DaloyJS monta automáticamente `GET /openapi.json` + `GET /openapi.yaml` (la especificación actualizada en ambos formatos) y `GET /docs` (una referencia de la API con Scalar):

```ts
const app = new App({
  bodyLimitBytes: 64 * 1024,
  requestTimeoutMs: 5_000,
  openapi: { info: { title: "Hello", version: "1.0.0" } },
  docs: "auto", // GET /docs, /openapi.json y /openapi.yaml fuera de producción
});
```

Abre `http://localhost:3000/docs` para ver la referencia interactiva de Scalar, `http://localhost:3000/openapi.json` para ver la especificación en JSON sin procesar o `http://localhost:3000/openapi.yaml` para verla en YAML.

En un servicio real, define `openapi.info` (o los campos de nivel superior `title`, `version` y `description`). Si los omites, DaloyJS usa los valores de respaldo portables `DaloyJS API` / `0.0.0`. El núcleo nunca lee el manifiesto del entorno anfitrión, así que el mismo bundle de documentación funciona en Node, Bun, Deno, Workers y Vercel.

¿Prefieres una función de fábrica? `createApp(options)` es un alias exportado de `new App(options)` y se comporta exactamente igual:

```ts
import { createApp } from "@daloyjs/core";

const app = createApp({
  docs: "auto", // usa true para publicar también la documentación en producción
  openapi: { info: { title: "My API", version: "1.0.0" } },
});
```

### ¿Prefieres la interfaz clásica de Swagger UI? [#prefieres-el-swagger-ui-de-siempre]

Scalar es la opción predeterminada porque es más rápida, más atractiva y funciona mejor en móviles. Pero si tu equipo está acostumbrado a Swagger UI, o si ya tienes capturas de pantalla, manuales de operación o hábitos de trabajo construidos en torno a ella, DaloyJS también la incluye sin configuración adicional. Cambia el campo `ui` cuando definas `docs` como objeto y volverás a la conocida interfaz verde:

```ts
const app = new App({
  openapi: { info: { title: "Hello", version: "1.0.0" } },
  docs: {
    ui: "swagger", // "scalar" (por defecto) | "swagger" | "redoc"
    path: "/docs", // opcional, cámbialo si prefieres /reference, /api-docs, etc.
  },
});
```

La misma URL (`GET /docs`), los mismos endpoints `/openapi.json` y `/openapi.yaml` con la especificación actualizada y el mismo manejo de la CSP; solo cambia el HTML que se muestra. También puedes mantener las dos: deja la ruta montada automáticamente con Scalar y expón tú mismo una segunda ruta con Swagger usando `swaggerUiHtml()` (consulta la [guía de OpenAPI](/es/docs/openapi) para ver cómo hacerlo manualmente).

¿Quieres una ruta personalizada? Define `docs` como objeto: `docs: { ui: "swagger", path: "/reference" }`. Cuando `docs` es un objeto, la documentación solo se monta fuera de producción, a menos que añadas `enabled: true` (desde la versión 1.5.5). Es el mismo comportamiento que `docs: "auto"`, que no monta las rutas cuando `production: true`. ¿Necesitas control total? Define `docs: false` y monta tus propias rutas con `generateOpenAPI()` y `swaggerUiHtml()` o `scalarHtml()`; consulta la [guía de OpenAPI](/es/docs/openapi).

Tanto `swaggerUiHtml()` como `scalarHtml()` cargan sus recursos predeterminados desde la CDN de jsDelivr, así que una Content-Security-Policy estricta debe permitir esos recursos; de lo contrario, la interfaz de documentación puede mostrarse en blanco. La ruta montada automáticamente y `htmlResponse()` añaden una CSP compatible de forma automática. Si construyes tu propia respuesta, importa `docsContentSecurityPolicy` desde `@daloyjs/core/docs` y pasa el resultado como encabezado de la respuesta:

```ts
import { docsContentSecurityPolicy } from "@daloyjs/core/docs";

headers: { "content-security-policy": docsContentSecurityPolicy() }
```

## 4. Usa el cliente tipado en el mismo proceso [#4-usa-el-cliente-tipado-en-proceso]

```ts
import { createInProcessClient } from "@daloyjs/core/client";

const client = createInProcessClient(app);
const r = await client.greet({ params: { name: "DaloyJS" } });
//    ^? { status: 200; body: { msg: string } }
console.log(r.status, r.body);
```

Los métodos del cliente se infieren a partir de la tupla de rutas de la aplicación. Encadena los registros de rutas o combina los contratos exportados con `defineRoute()` mediante `registerRoutes([...])`. Evita anotar el resultado solo como `App`, porque esa anotación amplía el tipo y, de forma deliberada, elimina la tupla.

## 5. Genera un SDK con Hey API

Para las aplicaciones que consumen la API fuera del monorepo, genera un SDK basado en fetch completamente tipado:

```bash
pnpm add -D @hey-api/openapi-ts@0.0.0-next-20260930190945 prettier
```

```ts
// openapi-ts.config.ts
import { defineConfig } from "@hey-api/openapi-ts";
export default defineConfig({
  input: "./generated/openapi.json",
  output: { path: "./generated/client", postProcess: ["prettier"] },
  plugins: ["@hey-api/client-fetch", "@hey-api/typescript", "@hey-api/sdk"],
});
```

Deja en ejecución el servidor de desarrollo del paso dos y, antes de ejecutar el generador del SDK, guarda en disco el documento OpenAPI actualizado:

```bash
mkdir -p generated
curl http://localhost:3000/openapi.json -o generated/openapi.json
pnpm exec openapi-ts
```

## Antes de desplegar

`new App()` ya activa los límites de tamaño del cuerpo, los tiempos de espera para las solicitudes, el análisis de JSON protegido contra la contaminación de prototipos, la ocultación de detalles en los errores 5xx en producción y `secureHeaders()`. Las claves y los cupos del límite de solicitudes dependen de cada despliegue, así que `rateLimit()` tienes que añadirlo de forma explícita:

```ts
app.use(rateLimit({ windowMs: 60_000, max: 120 }));
// Almacenamiento en memoria por defecto: un límite por proceso. Con N réplicas, el límite real es N × max.
```

Si ejecutas más de una instancia, conecta el [almacenamiento de límites de solicitudes en Redis](/docs/security/rate-limit-redis); de lo contrario, cada réplica lleva su propio contador.

La autenticación demuestra quién hizo la llamada, pero no demuestra que tenga permiso para leer ese registro. DaloyJS no puede aplicar por defecto la autorización a nivel de objeto, porque no conoce tu modelo de propiedad de los datos. Pon la comprobación en el handler o en la consulta, y sigue la guía de [autorización de recursos](/docs/security/resource-authorization), incluidas las pruebas de Alice contra Bob.
